Reading the Loom

Signal Loom treats a run of discrete beats as thread, not rows in a table. Each state re-threads the same count of beats into a different rhythm — spacing becomes shape, shape becomes meaning. The three measures below are read directly off the line currently drawn above. All values are exploratory sample data for this prototype; nothing here represents a real signal or performance.

Interval Count 10 How many discrete beats are threaded across the score right now.
Mean Spacing 100.0 su Average horizontal distance between beats, in abstract score units — not time.
Rhythm Variance 0.00 How unevenly the beats are spaced and raised, measured from the drawn line itself. Higher reads as more drifting or woven.
